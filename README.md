# QuietWall

一个优先考虑省电的原生 macOS 壁纸工具。支持本地静态图片、视频及 HTTP / HTTPS 网络直链；视频在电池供电、桌面被遮挡或系统需要休息时自动暂停。

使用 Swift、SwiftUI、AppKit 和 AVFoundation，无第三方运行时依赖。支持 macOS 13 及以上，兼容 Intel 和 Apple Silicon 源码构建。

## 已实现

- 菜单栏控制、中文壁纸库、居中页面切换、蓝色主题、静态预览和视频规格提示；窗口可调整大小，导入入口与历史常驻窗口内，本地文件通过系统文件选择器选择。
- 图片和视频均支持填充、适应、拉伸三种显示方式，设置和菜单栏可即时切换；预览同步更新，重启保留选择。
- 独立的绿色叶子应用图标，安装包包含 16–1024 像素的 macOS 图标资源。
- 导入 JPEG、PNG、HEIC、TIFF 等系统可解码图片；自动处理照片方向，多帧图片只显示第一帧。
- 导入系统可解码的本地视频（推荐 MP4 / MOV），静音循环播放。
- 输入 HTTP / HTTPS 图片或视频直链，下载后按实际内容自动识别，不依赖后缀或服务器 MIME 类型；支持重定向和取消下载。
- 网络壁纸缓存在本机，重启优先使用缓存；缓存缺失或损坏时重新下载，失败保留当前壁纸。
- 壁纸位于桌面图标下方，不接收鼠标事件，不改写系统壁纸。
- 保存壁纸引用和设置，下次启动自动恢复；移除壁纸不删除原文件。
- 壁纸历史保存最近 50 张成功使用的图片或视频，提供缩略图、最近使用时间、一键切换及单条移除；重复使用移到最前，重启保留。
- 默认只显示在主显示器，可切换所有显示器，多个显示器共用一个播放器。
- 手动暂停与恢复自动播放；显示具体暂停原因。
- 使用系统登录项服务设置开机启动。
- 异步验证图片或视频，加载失败时保留此前的壁纸；高分辨率或高帧率素材显示耗电提示。
- 菜单栏始终显示叶子，视频播放或静态图片显示时蓝色、视频暂停时灰色；操作失败可从菜单查看详情、打开设置或忽略提示，设置页保留错误说明。

## 文件夹轮换

在“壁纸来源”页中点击“选择文件夹…”，即可开始按文件名自然顺序循环图片和视频（例如 1、2、10）。只读取当前文件夹中系统可识别后缀的图片／视频，不包含隐藏文件、符号链接和子文件夹。每次切换重新读取目录，自动跳过无法解码的文件；文件夹为空或不可访问时保留当前壁纸，并在下次周期或点击“下一张”时重试。

- 周期支持 5 分钟、10 分钟、30 分钟、1 小时、每天、每周、每月。
- 自定义可设置 1–10000 分钟、小时或天，点击“应用”生效。修改周期从当前时间重新计时。
- 天、周、月按本地日历计算；每月从上次成功轮换或重试结束的时间加一个日历月，月末自动取目标月有效日期，不固定为 30 天。
- 开启后立即使用下一张；可随时关闭自动轮换或点击“下一张”。文件夹、周期、顺序进度和下次时间会保存，重启后继续。
- 使用单次定时器，不进行高频目录轮询，不唤醒设备。锁屏、切换用户、休眠或手动导入期间延后；恢复后过期周期只补换一次，不连续追赶。
- 手动选择本地／网络壁纸、使用历史壁纸或移除壁纸会关闭自动轮换，文件夹配置保留。
- 轮换沿用显示方式、壁纸历史及全部视频省电策略；手动暂停视频不会关闭轮换，新的视频仍遵守暂停状态。

## 壁纸历史

主窗口“壁纸库”页面下方以缩略图网格显示“最近使用”，也可通过菜单栏“壁纸历史…”打开。网格包含当前及之前成功使用的壁纸，按最近使用排序；点击缩略图切回，当前壁纸标有“当前”，卡片直接显示最近使用时间。同一本地文件或同一网络地址不会重复占位，最多保留 50 条，超出时移除最久未用的记录。

历史包含静态缩略图，浏览时不会播放视频或重新下载素材。本地文件只保存引用，需要保留原文件；即使原文件丢失，历史缩略图仍可查看。网络壁纸会保留缓存，切回时优先使用缓存，缓存缺失时重新下载。

“移除壁纸”只退出当前显示，历史仍然保留。“从历史移除”不会删除本地原文件，也不会中断当前显示；只有不再被当前壁纸或其他历史引用的网络缓存才会清理。记录及缩略图保存在本机 `~/Library/Application Support/QuietWall/wallpaper-history.json`。历史文件损坏或写入失败时会提示，仍允许应用和恢复有效壁纸，原历史不会被覆盖。此前版本已清理的旧壁纸无法追溯恢复，当前壁纸在成功恢复时会加入历史。

## 壁纸显示方式

在当前壁纸预览右侧或菜单栏“显示方式”中选择：

| 模式 | 显示效果 |
| --- | --- |
| 填充（默认） | 保持原比例铺满屏幕，超出部分居中裁剪 |
| 适应 | 保持原比例完整显示，空余区域为黑色，适合竖图或超宽图片 |
| 拉伸 | 不裁剪，拉伸至屏幕大小，可能改变画面比例 |

本地和网络图片、视频均使用同一选项。多显示器各自按屏幕比例显示；切换只更新图层，不重新下载、不重建播放器，也不改变暂停或省电状态。更换壁纸和重启后保留选择。

## 省电策略

静态图片不创建播放器或视频图层，也不运行遮挡检测定时器；电池、低电量模式和手动暂停等选项只影响视频。图片解码后复用同一画面，最长边超过 8192 像素时按比例缩小显示，不修改原文件。以下策略用于视频播放。

| 状态 | 行为 |
| --- | --- |
| 桌面可见、插电 | 正常播放 |
| 电池供电 | 默认暂停，可在设置关闭 |
| 桌面被一个或多个不透明窗口遮挡达到阈值 | 默认 95% 暂停，可选 90% / 95% / 100%，约 3–4 秒检测一次，也可关闭 |
| 低电量模式（包括插电时） | 默认暂停，可在设置关闭，或从当前状态、偏好设置及暂停菜单选择“允许低电量模式下播放” |
| 严重过热 | 自动暂停 |
| 锁屏、切换用户、显示器休眠、系统睡眠 | 自动暂停 |
| 系统开启“减少动态效果” | 自动暂停 |
| 手动暂停 | 保持暂停，不因插电、解锁或窗口变化自动恢复 |

暂停保留当前画面；尚未开始播放时显示视频首帧。恢复自动播放仍受省电策略约束。退出或移除壁纸后显示原系统壁纸。

采用 `AVQueuePlayer` / `AVPlayerLooper` / `AVPlayerLayer`，让系统选择解码路径；不强制高性能 GPU，不阻止系统睡眠。是否硬件解码取决于机型、编码与系统支持。Intel 双显卡机器启用自动显卡切换支持。

遮挡检查只读取窗口矩形元数据，不截屏。使用带 1 秒容差的 3 秒定时器；手动暂停、电池省电、锁屏、休眠等情况下停止此定时器。没有逐帧 CPU 回调、网页渲染器或后台转码。网络素材先完整下载，随后与本地文件共用同一播放和省电策略，不在循环播放时重复下载。

遮挡比例按桌面工作区域计算（不含菜单栏和 Dock），多个窗口重叠的面积只计算一次，普通及较高层级的置顶窗口均参与判断，壁纸自身、整体半透明窗口和 Dock 进程的系统窗口被排除。Dock 可能报告覆盖整屏、alpha 为 1 的透明窗口，因此按进程标识排除，避免桌面可见时误暂停。默认 95% 可容忍窗口之间的小缝隙；低于选定比例时恢复自动播放。阈值会保存，下次启动仍然生效。

恢复上次壁纸之前，先订阅系统事件并读取当前会话、登录、锁屏标志和显示器休眠状态。会话查询失败、登录未完成、没有可用显示器或显示器查询失败时保守暂停，后续通过会话及显示器事件更新状态。

**推荐 1080p、24–30 帧、SDR 的本地 H.264 / 设备支持的 HEVC 视频。** 本工具不自动降分辨率或降帧率；选择 4K / 高帧率素材仍会增加耗电。暂未提供实机功耗数据，不承诺固定 CPU 占用或续航损耗。

## 开发与检查

需要完整 Xcode 及其命令行工具，Swift 5.9 或更新版本。用 Xcode 打开 `Package.swift` 即可浏览项目。

```bash
./scripts/check.sh
```

检查脚本按 SwiftPM 模块边界分别检查核心库、应用和测试代码，生成的模块信息只放在临时目录；随后执行核心、图片解码及网络导入 XCTest 用例、检查 plist 和脚本语法，不构建或启动应用。核心测试覆盖省电优先级、唤醒和手动暂停冲突、遮挡比例边界、窗口重叠、置顶窗口过滤、负坐标显示器、无效配置以及启动时的会话和休眠状态。

图片测试使用临时生成的素材，覆盖 JPEG / PNG / HEIC / TIFF、照片旋转、GIF 首帧、超大图片限制和损坏文件拒绝。网络测试仅访问临时启动的本机回环 HTTP 服务，覆盖无后缀地址、错误后缀和 MIME 类型、图片／视频识别、重定向、HTTP 错误、非媒体内容、取消下载和离线缓存恢复，不依赖外部素材网站。历史测试覆盖重启恢复、缩略图、去重排序、条数限制、缓存引用、移除记录、原文件丢失及写入失败保护。本地导入另覆盖含空格／中文的路径与文件 URL、无效路径及文件夹拒绝。

需要完整 SwiftPM 测试时可手动执行 `swift test`；这会构建包。

应用图标保存在 `Resources/AppIcon.icns`，可在项目根目录运行 `swift scripts/generate-icon.swift` 从矢量绘图代码重新生成；正常打包直接复制该资源，无需重新绘制。

## 手动打包与使用

只有需要生成应用时才执行：

```bash
./scripts/package.sh
```

脚本输出 `dist/QuietWall.app`，默认包含当前构建机器的架构。执行 `./scripts/package.sh --universal` 可生成同时支持 Intel 和 Apple Silicon 的应用。使用本地临时签名，未做 Developer ID 签名与公证。

1. 将生成的 `QuietWall.app` 放到“应用程序”文件夹并打开。升级时先退出旧版，遇到同名提示选择“替换”；选择保留两份或重复解压可能使 macOS 自动添加“2”等文件名后缀。应用名称统一为 `QuietWall`。
2. 主窗口提供“壁纸库”“壁纸来源”和“偏好设置”三个居中标签页。“壁纸来源”页采用左右布局：左侧显示当前壁纸预览（按显示器比例缩放，最大 480 × 270 pt；视频使用封面，避免额外播放耗电），并保留加载状态及取消操作；右侧通过“本地文件 / 网络地址 / 文件夹轮换”三个标签页分别显示对应操作。“壁纸库”页保留当前壁纸显示控制和历史缩略图网格；省电与启动选项位于“偏好设置”页。点击右侧“图片或视频…”后在系统文件选择器中选中文件并确认，也可以将一个图片／视频拖到导入区域；切换到“网络地址”标签后，填写媒体直链并下载；“文件夹轮换”标签提供文件夹选择和轮换设置。切换来源标签本身不会停止正在运行的轮换。菜单栏入口会打开主窗口的对应来源。本地原文件请勿删除；下载或读取期间可取消。
3. 点击菜单栏叶子查看播放状态、替换壁纸或打开设置；视频播放或静态图片显示时叶子为蓝色，视频暂停时为灰色，图标形状保持不变。
4. 使用视频壁纸时，若处于电池供电，默认显示静态画面；插电且其他暂停条件解除后自动播放。系统低电量模式在插电时也可能开启，此时可点击菜单中的“允许低电量模式下播放”，也可在偏好设置的当前状态中操作，或关闭对应暂停选项（会增加能耗，不会更改系统设置）。
5. 开机启动若需系统批准，点击设置中的按钮前往“登录项”允许。

## GitHub 自动发布

发布与 `Resources/Info.plist` 应用版本一致的 Release（例如 `v0.1.0`）后，GitHub Actions 自动检查代码、执行核心测试、构建双架构应用并校验签名，最后上传以下文件到该 Release：

- `QuietWall-v版本号-universal.zip`：解压后得到 `QuietWall.app`，适用于 Intel / Apple Silicon。
- `SHA256SUMS.txt`：压缩包的 SHA-256 校验值。

也可在 Actions 的“发布 macOS 应用”工作流中手动输入已有 Release 标签重新打包。流水线始终检出标签指向的源码，标签和应用版本不一致时拒绝发布产物。

从 [Releases](https://github.com/black-lattice/QuietWall/releases) 下载后，将应用移入“应用程序”文件夹。由于应用尚未公证，首次打开可能被 Gatekeeper 拦截；确认下载来源后，可在系统“隐私与安全性”中允许该应用。

## 实机验收

文件夹轮换还需验证系统目录选择、长周期跨日与睡眠唤醒后的实际显示；自动化测试使用临时目录和可控时钟，不修改用户壁纸。

实机验收项目如下；核心检查另覆盖低电量模式开关、其他暂停条件不被绕过，以及 Dock 全屏窗口误判回归：

- 视频循环、暂停画面、桌面图标点击、Finder“显示桌面”。
- 最大化、多个窗口拼满屏幕、全屏应用、Mission Control、Spaces 切换。
- 拔插电源、低电量模式、锁屏解锁、睡眠唤醒、切换用户。
- 外接屏插拔、镜像屏、不同缩放比例和多屏模式。
- 图片 / 视频丢失、不可解码素材、图片与视频相互切换、重启恢复、移除壁纸与退出。
- 网络直链导入、下载取消、离线重启恢复、缓存丢失后重新下载，以及下载失败时保留当前壁纸。
- 主窗口缩放、壁纸网格与单页滚动、偏好设置页切换、文件选择与取消、文件拖入、本地／网络切换、错误提示，以及菜单栏入口定位。
- 历史浏览与切回、重复壁纸排序、删除当前或旧历史、本地文件丢失，以及历史中的网络壁纸离线切换。
- 横竖图片、透明 PNG、带旋转信息的照片、多帧图片首帧，以及静态图片在多屏和休眠唤醒后的显示。
- 横图、竖图、超宽图的填充／适应／拉伸切换、视频暂停及播放中的即时切换、不同屏幕比例，以及重启后显示方式恢复。
- 开机启动系统授权、深浅色界面和 VoiceOver。
- 三档遮挡比例切换与保存、置顶窗口覆盖、叶子状态颜色和关闭设置后的错误详情入口。
- 启动时已锁屏或显示器已休眠，以及状态查询失败后的恢复。

功耗应在同一亮度、同一素材、同一电源与显示器配置下比较：系统静态壁纸、QuietWall 可见播放、遮挡暂停各运行至少 5 分钟。观察活动监视器中 QuietWall 与 WindowServer 的 CPU、能耗及 GPU 使用情况。活动监视器“能耗影响”是相对指标，不应直接解释为瓦数。

## 已知边界

- 这是桌面壁纸窗口实现，不替换系统锁屏或屏幕保护程序。
- 遮挡判断使用窗口矩形与整体透明度，不能识别窗口内部透明区域、圆角或所有特殊系统窗口；无法取得有效数据时保持可见判断。多屏模式仅在所有目标屏幕分别达到选定遮挡比例时暂停共用播放器。
- 锁屏检测包含 macOS 的分布式通知及会话字典中可选的 `CGSSessionScreenIsLocked` 标志，与公开的会话及休眠接口共同使用。正常解锁时该标志可能缺省；分布式锁屏通知和此可选字段均不是 Apple 保证稳定的公开契约，需要随系统版本进行验收。
- 不修改系统壁纸文件，不申请辅助功能或屏幕录制权限。应用未启用 App Sandbox；源码仍需遵循正常本地应用信任流程。
- 设置、壁纸书签及网络来源地址仅保存于本机 UserDefaults。网络导入仅访问用户提供的服务器及其重定向目标；不读取浏览器登录态，不上传本地壁纸。
- 网络地址需直接返回系统支持的图片或视频文件，不支持网页解析、需要交互登录的下载、直播或 HLS 播放列表。下载请求空闲超时 60 秒，总时限 10 分钟，下载完成前保留原壁纸。
- 网络缓存保存在 `~/Library/Application Support/QuietWall/Downloads`；历史中的网络壁纸保留缓存；删除历史或达到 50 条上限时，仅清理不再被当前壁纸和其他记录引用的缓存。已有缓存不会自动刷新；需要更新时重新添加地址。

## 结构

- `Sources/QuietWall`：菜单栏、设置、图片解码、壁纸窗口、播放及系统状态监听。
- `Sources/QuietWallCore`：可独立测试的省电策略和矩形遮挡算法。
